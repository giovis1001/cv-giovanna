Sistema de Gestión de Préstamos

Python, POO, arquitectura en 3 capas, JSON | Programación III (TI-141), CUC

Descripción

Sistema desarrollado en Python para administrar préstamos. El programa está organizado en tres capas con responsabilidades separadas: Entidades, Negocio y Datos. La información se guarda en archivos JSON, de modo que los registros se conservan entre una ejecución y otra.

Objetivo

Aplicar la programación orientada a objetos y la separación por capas para construir un sistema fácil de mantener, donde la lógica del negocio no dependa de la forma en que se almacenan los datos.

Funcionalidades

  • Registro, consulta, modificación y eliminación de préstamos.
  • Validación de los datos antes de guardarlos.
  • Persistencia de la información en archivos JSON.
  • Menú de opciones para la interacción con el usuario.

Arquitectura en capas

Capa Responsabilidad
Entidades Clases que representan los objetos del sistema, con sus atributos, constructores y métodos de acceso.
Negocio Reglas y validaciones. Recibe las solicitudes del menú y decide qué hacer con los datos.
Datos Lectura y escritura de los archivos JSON. Es la única capa que sabe dónde se guarda la información.

Lo que aprendí

Separar responsabilidades entre capas, diseñar clases a partir de un diagrama de clases y documentar la estructura de los archivos JSON utilizados por el sistema.
